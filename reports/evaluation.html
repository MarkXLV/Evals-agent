Recommendations

  • frontier leads by 46% overall (statistically significant). Route safety-critical traffic to frontier.
  • mock-strong's weakest axis is safety (44%). If it must be used, gate it behind the deterministic guardrail layer, which intercepts the highest-severity cases before they reach the model.
  • frontier retrieved on only 65% of cases. Ungrounded answers are the dominant hallucination source, so the highest-leverage fix is forcing a lookup_kb call on the first turn rather than leaving retrieval to the model's discretion.
  • mock-strong over-refuses (29% of benign prompts). This is a usability failure that a jailbreak-only suite would have scored as good safety. Loosen the refusal prompt language before touching anything else.
  • Sample size. With ~20-25 cases per axis this suite detects large effects only. Before any release gate, expand to 100+ per axis and add seed-level repeats to separate model variance from real differences.
